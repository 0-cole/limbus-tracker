# Limbus Tracker

An automated, hyper-optimized Mirror Dungeon grind roadmap generator and resource tracker for Limbus Company.


## Download & Installation
**[📥 Download the Latest Version Here!](https://github.com/0-cole/limbus-tracker/releases/latest)**

1. Click the link above to go to the latest release page and download the installer.
2. Under **Assets**, download **Limbus Tracker Setup x.y.z.exe**.
3. Run the installer and follow the prompts. The tracker starts quietly in the background so it can open automatically when Limbus Company launches.
4. The setup installer is the recommended download for all Windows users.

> Windows may show a SmartScreen warning for an unsigned fan app. Download only from this project's official GitHub Releases page. The app does not need administrator privileges.

## Settings

* **Open when Limbus Company starts:** Enabled by default; turn it off in Dashboard → App Settings & Data to disable its quiet background startup and automatic game-launch behavior.
* **Season End (KST):** Update this in the Mirror Dungeon Schedule whenever a new season end date is announced, so the roadmap remains accurate.

## Features
* **Live Dashboard:** Get a bird's-eye view of your Season progress, Shard deficits, and upcoming resets.
* **Deterministic Math Engine:** Simply add IDs and E.G.O to your wishlist, and the engine will calculate exactly how many Egoshard Crates and Battle Pass levels you need.
* **Automated Timeline:** Generates a complete, day-by-day roadmap telling you exactly when to run your Mirror Dungeons to perfectly hit your goals by the season's end.
* **Perfect Sync:** Flawlessly synchronized with Limbus Company's weekly changeover servers (06:00 AM KST), automatically replenishing Mirror Dungeon bonuses precisely when the game does.
* **Enkephalin Module Calculator:** A live, dynamically updated tracker on the Inventory tab that tells you exactly how many modules are required to fund your entire remaining roadmap.
